# 05 · 工具使用、工作流与多智能体自优化

## 场景定义

优化提示、工作流图、多智能体角色与工具编排；或让 agent 在运行时改自己的代码（monkey patch）。

## 为什么适合 / 不适合 RSI

| 因素 | 评估 |
|------|------|
| 验证器 | **中**：有开发集分数则可；开放任务弱 |
| 适合 | 搜索空间离散、可版本化（图、提示、代码字符串） |
| 典型层级 | 绝大多数是 **L0**；Gödel Agent / Promptbreeder 更接近 L1 / 部分 L2 |

## 场景小结

- 本场景是 **L0 基础设施**大本营：把「找更好 agent」变成搜索问题。  
- **Promptbreeder** 因同时进化 mutation-prompts，是少有的「部分 L2」提示进化例子。  
- **Gödel Agent** 名称呼应理论 RSI，实现上是运行时自改，作者语境仍非经典智能爆炸。

## 开放问题

1. 工作流搜索的迁移：在 A 任务搜到的图是否在 B 任务保持优势？  
2. 自修改代码的安全默认（权限、回滚、审计）。  
3. 将 L0 工作流优化器与 L1 编码自进化对接。
