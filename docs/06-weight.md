# 06 · 权重级自我训练 / Self-play / Self-rewarding

## 场景定义

模型用自生成数据、自打分或自对弈更新**权重**（SFT/RL），而非只改提示或脚手架。

## 为什么适合 / 不适合 RSI

| 因素 | 评估 |
|------|------|
| 验证器 | 可强（数学/代码执行）或弱（自奖励模型） |
| 适合 | 真正改变「策略分布」；可跨任务泛化 |
| 风险 | 奖励黑客、自偏好放大、有害推理；外环仍常固定 |

## 场景小结

- 这是公开文献里最接近「模型递归变强」的路径（**L3**）。  
- Self-Rewarding / Meta-Rewarding 让 **评判器**也变，带一点 L2 味道，但优化目标与训练代码通常仍人类固定。  
- Absolute Zero / R-Zero 把「无外部数据」推到极端，同时把 **对齐风险**推到前台。

## 开放问题

1. 自奖励是否必然奖励黑客？可证明的缓解有哪些？  
2. L3 与 L1 脚手架自进化如何安全组合（训练 + 运行时改代码）？  
3. 跨代复合：多轮 self-play 后是否持续收益还是崩溃。
