# 04 · 具身 / 游戏 / 开放世界

## 场景定义

在 Minecraft、机器人仿真/真机等环境中，agent 通过技能库、经验记忆、奖励代码搜索或提出–生成–学习循环提升长期能力。

## 场景小结

- Voyager / JARVIS-1 = 技能与记忆累积的经典 **L0–L1** 叙事。  
- Eureka / DrEureka 表明：在**固定外环**下，LLM 可重写**奖励（及 DR）代码**——层级上仍偏 **L0**（搜索对象是奖励程序，不是改进机制本身）。  
- ExpeL 是纯 **L1 经验洞察**、不更新权重的对照。  
- 真机自改进受安全与样本成本强烈制约；公开可复核「机器人 foundation model 自我改进」证据仍薄。

## 开放问题

1. 技能库增长是否等于元学习能力增长？  
2. 仿真到真机的自改进迁移与安全熔断。  
3. 奖励代码搜索被 LLM「黑」掉物理约束时如何检测。
