# 02 · 科研自动化 / AI Scientist / Auto ML R&D

## 场景定义

用 agent 做假设、实验、写论文、改训练代码或搜索算法，目标是自动化（或部分自动化）AI/ML 研究本身。

## 为什么适合 / 不适合 RSI

| 因素 | 评估 |
|------|------|
| 验证器 | **中–弱**：指标可自动，但「是否算新科学」依赖人类；竞赛/Kaggle 相对更强 |
| 修改空间 | 实验脚本、搜索程序、论文草稿可改；真正改「科研品味」难 |
| 适合点 | AlphaEvolve 类：有明确度量的算法/系统优化 |
| 不适合点 | 开放式发现易模式坍缩；评审标准漂移 |

## 场景小结

- 「AI Scientist」证明流水线可闭环出文，但外层科研流程多 **固定（L0–L1）**。  
- AlphaEvolve 是 **强验证器 + 程序进化** 的标杆，属经典 L0 搜索，却能反哺真实 Gemini/Borg——说明 **价值在验证器与部署闭环**。  
- AI co-scientist 把「锦标赛式假设进化」推进到生物医学，仍属 **L0–L1**。  
- MLGym 作者结论尖锐：当前前沿模型在开放 AI 研究任务上**多在调参，少有新算法**。  
- RE / MLE / PaperBench 把「自动化 AI R&D」变成可比较分数，是治理与能力追踪的关键基础设施。
